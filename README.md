# Pathora

Pathora é uma plataforma web em desenvolvimento para monitoramento de riscos ambientais e epidemiológicos.

O projeto busca reunir dados, alertas e visualizações para ajudar na prevenção de surtos e no acompanhamento de regiões de risco.

## Status

Em desenvolvimento.

## Funcionalidades

- Landing page institucional
- Página de login e cadastro
- Dashboard inicial de risco
- Estrutura de backend em Python
- Integração com inteligência artificial
- Sistema preparado para mapas e alertas

## Tecnologias utilizadas

- HTML5
- CSS
- JavaScript
- Python
- Flask

## Cypher AI

O projeto possui integração com a Cypher AI, uma inteligência artificial desenvolvida por Lucas para auxiliar em análises, prevenção e monitoramento de riscos.

A IA foi criada com Python e possui estrutura preparada para integração com modelos locais e APIs de IA, incluindo:

- Ollama
- Groq
- Gemini

## Objetivo do projeto

O objetivo do Pathora é unir tecnologia, monitoramento e inteligência artificial em uma plataforma acessível e moderna para análise de riscos e prevenção.

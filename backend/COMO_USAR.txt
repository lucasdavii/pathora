COMO USAR O BACKEND ORGANIZADO DO PATHORA

1. Coloque estes arquivos dentro da pasta backend:
   - cypher_ai.py
   - identidade.txt
   - base_conhecimento.txt
   - .env

2. Se ainda não tiver .env:
   - copie .env.example
   - renomeie para .env
   - preencha suas chaves reais

3. Instale as dependências:
   pip install -r requirements.txt

4. Rode o backend:
   python cypher_ai.py

5. Teste no navegador:
   http://localhost:5000/health

6. Se aparecer status online, o backend está funcionando.

Observação:
Os arquivos gemini_service.py, groq_service.py e ollama_service.py não são mais necessários com este cypher_ai.py.
Guarde como backup primeiro. Depois de testar, pode remover.
